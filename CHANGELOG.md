# Changelog

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).
Версионирование: [SemVer](https://semver.org/lang/ru/).

Релизы сгруппированы по минорным веткам внутри `changelog/`. Каждый файл содержит блоки патч-релизов своей ветки (свежие сверху).

- [0.19.0] — рабочий Storybook 10 (40+ историй), разделение UI на atoms/molecules/organisms с линтер-границами, темизация через Global Toolbar (+ сетка тем в песочницах), `docs/storybook.md`.
- [0.18.1] — глобальный поиск дубликатов по всей библиотеке (кнопка «Похожие треки» на HomeView), фикс alphabet scroll в ArtistsView, устранение дублирования autosize в LogiiVibeBlock, e2e-тесты склейки треков и метаданных.
- [0.18.0] — confluence-подобная документация проекта в `docs/`, AST-генератор манифеста экспортов, фикс склейки одинаковых треков из разных подпапок.
