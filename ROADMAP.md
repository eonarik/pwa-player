# Roadmap (от 0.15.0 до 1.0.0)

## [0.15.0] — Стабильный синк, Файловый менеджер и Умный локальный доступ (Текущий релиз)

Цель: Устранение архитектурной нестабильности синхронизации и расширение возможностей работы с файлами.

- [x] Глобальный рефакторинг синхронизации (Sync 2.0): первичный, фоновый (доскан) и force scan.
- [x] Реестр обработчиков файлов (FileHandlerRegistry) с поддержкой плагинов.
- [x] Обработчик `.txt` с 3-way merge и обработчик изображений с фуллскрином.
- [x] Восстановление структуры из локальной папки (restoreFromLocalFiles) для офлайн-работы.
- [x] Оптимизация библиотеки (`folder.files`, мьютексы в `LibraryWriter`).
- [x] Исправление ошибок с путями на бэкенде Yandex-Self.
- [x] Удаление зависимости `radio-browser-api`.

## [0.15.1] — Групповое редактирование и UX-полировка

Цель: Улучшение работы с библиотекой и массовые действия.

- [ ] Групповое редактирование: Выделение нескольких треков чекбоксами и массовые действия (удаление, скачивание, добавление в плейлист).
- [ ] Обновление документации (README, CONTRIBUTING, архитектурные гайды).
- [ ] Deep Links (Ссылки на плейлисты): Открытие плейлиста по URL (например, `https://cuei.app/import?data=CUEI1:...`) с обработкой в `App.vue`.
- [ ] Обработка ошибок ClipboardWatcher: Понятные тосты, если буфер обмена запрещен браузером.
- [ ] **Свайпы на TrackRow:** Быстрое добавление в избранное / дизлайк (для мобильных устройств).

## [0.16.0] — Продвинутая работа с файлами и Экосистема

Цель: Расширение форматов файлов и внедрение плагинов сторонних разработчиков.

- [ ] **Просмотр PDF и EPUB:** Добавление соответствующих обработчиков в `FileHandlerRegistry`.
- [ ] **Импорт плейлистов из стримингов:** Через `PluginExtension.importActions` (Яндекс.Музыка, Spotify и т.д.).
- [ ] **«Волна» (бесконечный поток):** Генерация очереди на основе текущего трека (локально + Звук).
- [ ] **Module Federation (Remote Plugins):** Загрузка сторонних плагинов по URL.
- [ ] **Пользовательские темы:** Загрузка своего CSS/JSON с палитрой.
- [ ] **Эквалайзер (Web Audio API):** 10-полосный с пресетами.
- [ ] **Синхронизация настроек:** Экспорт/импорт `uiSettings` и `player:state`.

## [0.17.0] — Офлайн и Фоновая работа

Цель: Максимальная автономность и стабильность работы с большими библиотеками.

- [ ] **Автосинк (Delta Sync):** Умная синхронизация библиотеки с проверкой `modified` (изменение только изменившихся файлов).
- [ ] **TaskManager:** Пул задач для фоновых процессов (сканирование, метаданные, скачивание).
- [ ] **Полноценный Service Worker:** Кэширование обложек и аудио-стримов.
- [ ] **Умное скачивание:** Автоматическое сохранение играющих треков в фоне.
- [ ] **Синхронизация скачанного:** Проверка целостности файлов и перекачивание битых.

## [1.0.0] — Публичный релиз

Цель: Полировка UX, документация, мобильная адаптация.

- [ ] Мобильное приложение (Capacitor).
- [ ] Документация плагинов и SDK.
- [ ] PWA-улучшения (Background Sync, Share Target).
- [ ] Глобальный рефакторинг UI.
- [ ] Аудит безопасности.
