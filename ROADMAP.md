# Roadmap (от 0.12.2 до 1.0.0)

## [0.12.2] — Стабильность ядра и Архитектура (Завершено)

Цель: Закрыть все архитектурные дыры, связанные с удалением источников и мультиисточниками.

- [x] Мертвые треки: Не удалять трек из библиотеки, если на него есть ссылки (плейлисты, история, дизлайки, очередь, альбомы). Чистить только `sources`.
- [x] Очистка очереди: При отключении плагина останавливать воспроизведение треков из него и удалять их из `player:queue`.
- [x] Сборщик мусора (`cleanupOrphanTracks`): Удалять из библиотеки «треки-сироты» (без источников и без ссылок в коллекциях) при старте приложения.
- [x] UI плейлистов: Корректно отображать мертвые треки как «Источник недоступен» (зачеркнутые).
- [x] Кнопка «Поделиться»: Починить DropdownMenu.
- [x] `logger`: Централизованная точка логирования (глушится в тестах/проде).
- [x] CI/CD: Настроен pre-push (Husky) и GitHub Actions (E2E только на main).
- [x] Фикс альбомов: Дать возможность создавать/удалять альбомы вручную.
- [x] UI метаданных: Перевести выпадашку «Найденные варианты» на Teleport, переместить наверх.
- [x] Источники Звука: При строгом совпадении автоматически добавлять стриминговый `source` в трек.
- [x] Фича «Найти в Звуке»: Кнопка для поиска недоступных треков в коллекциях.
- [x] Суммаризация тостов: Защита от лавины одинаковых ошибок.
- [x] Архитектура `extMetadata`: Ядро больше не знает о `trackId` провайдеров.

## [0.13.0] — Оптимизация библиотеки и Умный плеер (Текущий релиз)

Цель: Ускорить работу с большими библиотеками, улучшить UX плеера и добавить «умные» функции.

- [ ] Фикс шафла: Сохранение исходного порядка очереди при включении/выключении шафла.
- [ ] Виртуализация сеток: Альбомы и Артисты (виртуализация строк).
- [ ] Alphabet Index: Быстрый скролл по буквам на страницах Альбомов и Артистов.
- [ ] Умный автопоиск: Очередь с приоритетами, визуальный прогресс и возможность отмены.
- [ ] Кэш поиска: Индекс для SearchView и ArtistsView (MiniSearch).
- [ ] Оптимизация IndexedDB: Инкрементное сохранение библиотеки.
- [ ] Групповое редактирование: Выделение нескольких треков и массовые действия.
- [ ] Unified Search: Поиск по всем источникам (включая Звук) в SearchView через `PluginSearchAction`.
- [ ] Простые умные плейлисты: Автоматические плейлисты по правилам (жанр, год и т.д.).
- [ ] «Продолжить слушать»: Восстановление позиции очереди и прогресса при старте.
- [ ] Свайпы в FullPlayer (prev/next) для мобильных устройств.
- [ ] Кэш http-обложек: Сохранение обложек в Cache Storage (для офлайна).
- [ ] `reconcileFolderTrackIds` в runtime: Батчинг и `requestIdleCallback`.
- [ ] Единый `MetadataFetchQueue`: Унификация `runAutoFetch` и `restoreUnavailable`.
- [ ] VueUse: Подключение утилит (IntersectionObserver, Swipe, MediaQuery).
- [ ] Скачивание стримов (Zvuk, Radio) с серверным рубильником (фича-флаг).
- [ ] Crossfade (плавный переход треков через Web Audio API).

## [0.14.0] — Плагинная экосистема и Кастомизация

Цель: Сделать плеер расширяемым без пересборки ядра.

- [ ] Module Federation (Remote Plugins): Загрузка сторонних плагинов по URL.
- [ ] Импорт плейлистов из стримингов: Через `PluginExtension.importActions`.
- [ ] «Волна» (бесконечный поток): Генерация очереди на основе текущего трека (локально + Звук).
- [ ] Свайпы на TrackRow: Быстрое добавление в избранное / дизлайк.
- [ ] Пользовательские темы: Загрузка своего CSS/JSON с палитрой.
- [ ] Эквалайзер (Web Audio API): 10-полосный с пресетами.
- [ ] Синхронизация настроек: Экспорт/импорт `uiSettings` и `player:state`.

## [0.15.0] — Офлайн и Кэширование

Цель: Максимальная автономность.

- [ ] Полноценный Service Worker: Кэширование обложек и аудио-стримов.
- [ ] Умное скачивание: Автоматическое сохранение играющих треков.
- [ ] Синхронизация скачанного: Проверка целостности файлов и перекачивание битых.

## [1.0.0] — Публичный релиз

Цель: Полировка UX, документация, мобильная адаптация.

- [ ] Мобильное приложение (Capacitor).
- [ ] Документация плагинов и SDK.
- [ ] PWA-улучшения (Background Sync, Share Target).
- [ ] Глобальный рефакторинг UI.
- [ ] Аудит безопасности.
