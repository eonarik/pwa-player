# CUEI Media Player

Офлайн PWA-плеер для музыкальной библиотеки. Работает напрямую с локальной файловой системой через File System Access API, а также с облачными сервисами (Яндекс.Диск, СберЗвук) через собственный прокси. Без загрузки файлов на сторонние серверы, без аккаунтов, без интернета для локальной библиотеки.

## Ключевые возможности

- **Единая библиотека:** локальные папки, Яндекс.Диск и СберЗвук в одном интерфейсе.
- **Стриминг и офлайн:** слушайте музыку из облака или скачивайте её на устройство для прослушивания без интернета.
- **Продвинутый поиск:** fuzzy-поиск с поддержкой разных раскладок (QWERTY ↔ ЙЦУКЕН) и транслитерации.
- **Умные метаданные:** четкая иерархия (ручные правки > теги из файла > автопоиск в интернете > имя файла). Автоматическое распознавание ID3-тегов.
- **Плейлисты и история:** сохранение треков из любых источников (включая стриминговые) в плейлисты с сохранением обложек и длительности.
- **Настраиваемый интерфейс:** тёмная тема, ретро-радио, киберпанк и тема «Барби». Умный автоскролл и шафл.
- **PWA:** устанавливается на устройство, работает офлайн (для локальной библиотеки).

## Технологии

- **Фронтенд:** Vue 3, TypeScript, Pinia, Vue Router, Tailwind CSS v4, Vite.
- **Бэкенд:** Node.js 22, Express.
- **Хранение данных:** IndexedDB (idb-keyval), File System Access API.
- **Инфраструктура:** PWA (vite-plugin-pwa), Nginx, PM2.

## Установка и запуск

```bash
# Клонировать репозиторий
git clone <url>
cd cuei-player

# Установить зависимости
yarn install

# Запустить dev-сервер (фронтенд + бэкенд)
yarn dev

# Собрать production-сборку
yarn build

# Прогнать тесты
yarn test:unit --run
```

## Плагины (источники)

Ядро не знает про конкретные источники — всё общение идёт через контракт LibrarySource. Плагины можно включать и выключать в настройках.

- **Локальная папка (local):** прямое сканирование папок на диске.
- **Яндекс.Диск (yandex):** облачная библиотека с возможностью скачивания на устройство.
- **СберЗвук (zvuk):** поиск и стриминг музыки из каталога Звука.
- **Онлайн-Радио (radio):** каталог радиостанций (Radio Browser).
- **Подкасты (podcasts):** каталог подкастов (Apple Podcasts) с подписками.

## Требования и особенности

- Десктоп: Chrome 86+, Edge 86+, Opera 72+.
- Мобильные: локальная библиотека не работает (нет File System Access API). Доступны Яндекс.Диск (через прокси) и стриминговые сервисы.

## Архитектура

Проект построен на плагинной архитектуре:

- Ядро предоставляет UI, плеер, очередь и библиотеку. Оно не знает про конкретные источники данных.
- Плагины реализуют контракт LibrarySource (сканирование, стриминг, скачивание).
- MetadataService — единая точка изменения метаданных, которая синхронизирует библиотеку, очередь и кэш.
- ApiClient — единый HTTP-клиент с поддержкой AuthProvider для рефреша токенов и обработки ошибок.
