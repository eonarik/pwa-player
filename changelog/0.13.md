# Changelog 0.13.x

> Релизы: 0.13.3, 0.13.2, 0.13.1, 0.13.0

## [0.13.3] — Оптимизация синхронизации и UI

### Added

- `libraryIndex` (Map по артистам) в `TrackMerger`/`PlaylistMatcher`.
- Кэш `layoutVariants`.
- `content-visibility: auto` в `ListRow`.

### Changed

- Батчинг `onChunk` — раз в 1500 мс.
- Сортировка папок/треков при сканировании.
- Отложенное сохранение в IDB (`requestIdleCallback`).
- `FolderView`/`FolderListItem` без рекурсивного пересчёта; `subtreeTracksMap`
  и `folderStats` в `libraryStore`.
- `FolderSyncMenu` блокируется при фоновом сканировании.
- `TrackMerger` разбит на модули.
- `dislikes`/`history`/`playlists` — общий хелпер `merge`/`apply`.

### Fixed

- Фризы при сканировании; `DataCloneError`; долгое сканирование; дубликаты
  альбомов; бесконечный поток ошибок.

### Removed

- `LibraryPersistenceService` (Web Worker) — `FileSystemFileHandle` не
  передаётся через `postMessage`.

## [0.13.2] — Стабильность и Архитектура синхронизации

### Added

- Зафиксирована задача на исключения папок (перенесено на 0.14.x).

### Changed

- Параллельный обход папок (concurrency 5).
- `setLibrary` (Mutex) — очередь `onChunk` против race.
- `ReconciliationService` — убран ложный `void library`.
- `DownloadOrchestrator` пробрасывает ошибку, тост показывает `TrackActions`.

### Fixed

- Дубликаты альбомов; долгое сканирование; вводящий в заблуждение тост
  «Библиотека будет пересобрана...».

## [0.13.1] — Мобильный UX и Улучшения интерфейса

### Added

- Top Bar: поиск, плейлисты, избранное, настройки; подсветка активного раздела.
- Тосты при добавлении/удалении из плейлиста; галочка принадлежности в меню.
- `getAllSettingsSchemas` без кэша.

### Changed

- `PlaylistSubmenu` — toggle без закрытия меню.
- Настройки локальных папок обновляются мгновенно.
- Мобильная адаптация `AlbumsView`/`ArtistsView`; переключатель вида скрыт,
  шапка переносится.
- `VirtualGrid`: `forcedColumns`, `sectionGap`, дженерики.

### Fixed

- Тултипы на touch; обрезка текста в плитках; сохранение вида; размеры плиток.

## [0.13.0] — Оптимизация библиотеки и Умный плеер

### Added

- `VirtualGrid` (TanStack Virtual) для альбомов/артистов.
- Alphabet Index (A-Z) с pointer-событиями и «кареткой».
- Сохранение вида (плитка/список) в `localStorage`.
- Группировка по артистам на «Альбомах».
- Mobile UX: принудительный список при < 768px.

### Changed

- `ViewToggle`, `AlphabetIndex` (ограничение высоты), `player/actions.ts`
  разбит на модули.
- Шафл: `originalQueue` сохраняется, при выключении восстанавливается порядок.

### Fixed

- Сброс порядка при выключении шафла; узкий контейнер; пустые промежутки
  в виртуализированных списках.
