# Changelog 0.10.x

> Релизы: 0.10.7, 0.10.6, 0.10.5, 0.10.4, 0.10.3, 0.10.2, 0.10.1, 0.10.0

## [0.10.7] — 2026-11-01

### Added

- Приоритеты `metaSource` (manual/file/auto/filename); `hasId3Tags`.
- Умный автоскролл к текущему треку.
- Спиннер скачивания на обложке; `unknown`-флаг против шторма запросов.

### Changed

- Сброс метаданных через `raw`; автопоиск не перезаписывает `file`/`manual`.
- `similarity.js`: промежуточный порог для похожих артистов.
- `yandex`/`yandex-self` подключены только при валидном токене.
- Открытие локальных папок: кэш сразу, диск — в фоне.

### Fixed

- Повторный автопоиск; шторм запросов; залипание альбома/обложки; фантомное
  подключение; удаление данных при отключении; иконки в меню Барби.

## [0.10.6] — 2026-10-28

### Added

- Автоскачивание при воспроизведении (настройки + быстрое меню).

### Changed

- Скачивание на бэкенде: 3 попытки, таймаут 15 с, `Connection: close`.
- `DownloadOrchestrator`: 3 попытки с паузой 2 с.
- Логирование `cause` ошибок скачивания.

### Fixed

- Индикация скачивания в теме Барби; ошибки `fetch failed` из облака.

## [0.10.5] — 2026-10-27

### Added

- Тема «Барби»: палитра, шрифты, облака; пульсирующая звезда играющего трека,
  голубой ободок скачанного, полупрозрачные дизлайки.
- Умный автоскролл в списках треков.
- Заглушка `track-cover_empty`.

### Changed

- `setQueue`/`playAll`/`next`/`prev` при шафле работают по перемешанному
  массиву.
- Меню в теме Барби — «театральная программка».

### Fixed

- Дизлайк не блокирует явный клик; шафл + клик по треку; очередь при клике;
  правый бордер в меню Барби.

## [0.10.4] — 2026-10-25

### Added

- `ApiClient` (AuthProvider, refresh, retry 401, типизированные ошибки,
  healthCheck/ensureAuth).
- AuthProvider для `yandex-self` и `yandex`.
- `connectPlugin` без редиректа; `ensureAuth` в `resolveTrackSource`;
  тост «Подключить»; `handleStreamError` через `healthCheck`.
- `MetadataService` — единая точка изменения метаданных с дебаунсом.
- Тесты `yandex-self /auth/check` и интеграционные тесты плеера.

### Changed

- `playAt` перехватывает `AuthError`; `playAll`/`setQueue` через
  `findFirstPlayableIndex`.
- `TrackRow` использует `isTrackUnavailable`; `NowPlayingInfo`/`FullPlayer` —
  `coverUrl` из library.
- `playerRestore` без переноса `coverUrl`.

### Fixed

- `playAll` для `yandex-self`; кнопка «Пауза» в мини-плеере; ручное
  редактирование/удаление метаданных синхронизирует очередь.

### Removed

- `MetadataApplier`, `player.updateTrackInQueue` из UI,
  `metadataPersistenceService.flush` из UI, `plugin.handleStreamError`.

## [0.10.3] — 2026-10-24

### Added

- Storybook (примитивы и сложные компоненты, тулбар тем).
- UI-система: `ICONS` + `Icon.vue`, `useButtonAs`, `SettingsActionRow`,
  `PageHeader`, `ListContainer`, `EmptyState` (слот `#icon`).
- Темизация иконок (`.icon`, градиенты в radio/neon).

### Changed

- `AppDrawer`/`menu.ts`/`PluginMenuItem` — иконки строками.
- `TextEditorModal` на `ModalLayout`, настоящий фулскрин.
- `ToastHost`, `ModalHost`, `CatalogLayout`, `PlaylistHeader`,
  `PlaylistToolbar`, `PlaylistShareMenu`, `FolderList`, `FolderSettingsMenu`,
  `FolderSyncMenu`, `FolderSortMenu`, `MetadataMenu`, `TrackActions`,
  `PlayerControls`, `FullPlayer`, настройки, `FileListItem`, `TrackResolvedItem`,
  `CoverImage`, `CoverPicker`, `FolderBreadcrumbs` — на `Icon`/`IconButton`.

### Fixed

- Иконки в ретро/неоне; порядок кнопок в `TextEditorModal`; `EmptyState`
  без импорта иконки.

## [0.10.2] — 2026-10-24

### Added

- Импорт радио по URL (favicon через Google S2).
- `/api/hls-proxy` — CORS для HLS-радио.
- Импорт подкастов по RSS и из OPML (с прогрессом).
- Бэкап/восстановление `cuei-backup.json` (выборочно по доменам).
- Быстрый фильтр в поиске (Все/Локальные/Облако).

### Changed

- Подкасты → IndexedDB (без `QuotaExceededError`); API асинхронный.
- `AudioService`/`player`: защита от фантомного воспроизведения.
- Плеер блокирует недоступные треки.

### Fixed

- Недоступные треки после перезагрузки; `not-found`-кэш 7 дней;
  `yandex-self` 401 (race в refresh); `playAt` при навигации.

## [0.10.1] — 2026-10-23

### Added

- `FileLocation`/`ScanState`, селекторы `getPlayability` и др.
- `resolveTrackSource`, `track.handle`, `plugins/registry` с реактивным кэшем,
  `assertTrackInvariants`, `subtreeCache`, `mergeLocalIntoLibrary`,
  `updateTrackHandle`, миграции.

### Changed

- `Track.source` — только `string`; `playAt` async.
- `LibraryWriter`: `updateTrackFileLocation`/`updateTrackHandle`.
- Плагины `local`/`yandexDisk`/`yandex-self` используют `handle`/`fileLocation`.
- `DownloadOrchestrator`/`SyncService` через `handle`.
- `downloadUrlToFile` возвращает `{ size, handle }`.

### Fixed

- «Открыть локально» (yandex/yandex-self/local); «Синхронизация с устройства»
  открывается автоматически; `FolderContent` при `min-h-0`; дубли
  `folder.trackIds`; полоска «скачано»; `buildDownloadUrl`;
  `removeDownloaded`; `local` при пустом плагине; `getPlayability`;
  `similarity.spec`; `uiSettings.spec`; `scanFolder.spec`/`selectors`/`library`.

### Removed

- `TrackOrigin`, `ScanStatus`, `Folder.ready`, `LibraryTrack.origin`,
  `updateTrackOrigin`, маппинги legacy, `File` в `source`.

## [0.10.0] — 2026-10-23

### Added

- `ThemeService` + темы «Тёмная», «Ретро-радио», «Киберпанк» (сохранение,
  `data-theme`).
- Глобальные SVG-градиенты для иконок.

### Changed

- `SettingsGeneral` — селектор темы; `PlayerControls` — `.player-play-pause-btn`;
  `PlayingIndicator` — `variant` (bars/eye); `PlayerProgressBar` — латунный
  градиент; `FullPlayer` — янтарная подсветка в ретро.

### Fixed

- Конфликт заливки иконок на кнопках Play/Pause.
