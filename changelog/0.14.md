# Changelog 0.14.x

## [0.14.0] — Плейлисты и Шаринг

### Added

- Шаринг плейлистов (`CUEI1:` + gzip + Base64URL).
- `ImportPlaylistModal`: вставить из буфера / выбрать файл / вставить вручную.
- Умная кнопка «Поделиться» (`navigator.share` / копирование / файл M3U/JSON).
- `ImportService` — парсинг трёх форматов, матчинг, статистика.
- `useClipboardWatcher` с защитой от фантомных тостов.

### Changed

- `PlaylistsView` «Импортировать» → `ImportPlaylistModal`.
- `BatchDownloadButton` — текст «Скачать треки».

### Fixed

- Дубли кнопок в модалке шаринга; E2E шаринга и `ClipboardWatcher`.
