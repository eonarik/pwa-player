# Changelog 0.16.x

> Релизы: 0.16.3, 0.16.2, 0.16.1, 0.16.0

## [0.16.3] — Стабилизация после 0.16.2

### Added

- `metadataProviderEnabled` — флаги включённости провайдеров (`undefined` = вкл).
- Тосты «Найдено N» с action «Открыть».
- `MetadataProvidersList`: drag-and-drop сохраняет позицию выключенных.
- Спеки на диакритику `PlaylistMatcher` и миграцию бэкапа v1 → v2.

### Changed

- `metadataProviderOrder` хранит все id; `toggleMetadataProvider(id, false)` не
  удаляет из порядка.
- `resolve.ts` фильтрует по `isMetadataProviderEnabled`.
- `sourceKey` для `local` включает `folderId`; `local → cloud` fallback — только
  при однозначности.
- README/ROADMAP актуализированы.

### Fixed

- `sourceKey` collision для `local` (два `track.mp3` в разных папках).
- `local → cloud` fallback склеивал с первым найденным при 2+ совпадениях.
- UX тоста «Найдено N» (нужен action «Открыть»).
- Drag-and-drop в `MetadataProvidersList` терял порядок при переключении.
- Миграция v1 → v2 в `BackupService`.
- Legacy-ключ `zvuk:fetchMetadata` → `metadataProviderEnabled`.

### Internal

- Обновлены спеки (`PlaylistMatcher`, `BackupService`, `sourceKey`,
  `applyCandidate`, `useMetadataSearch`) и E2E `05`, `07`.

## [0.16.2] — Строгий мэтчинг и плагинная граница

### Added

- `PluginManifest.metadataPriority` — приоритет провайдера метаданных.
- `uiSettings.metadataProviderOrder` + drag-and-drop в настройках.
- `PluginManifest.backup` (declarative), `PluginSnapshot.alreadyApplied`.
- `sourceKey` в `TrackMerger` — защита от дубликатов при сканировании.
- `TrackMerger`: склейка `local → cloud` по имени файла.
- `TrackMetadataService.fetchItunes` / `fetchDeezer` вместо общего `fetch`.

### Changed

- `PlaylistMatcher.findBestMatch` переписан на строгие правила
  (strict 1.0 / soft 0.9 / иначе `null`), Jaro-Winkler убран.
- `MetadataService.resolve` итерируется по `metadataProviderOrder`; Zvuk больше
  не хардкод.
- `BackupService` собирает/восстанавливает через `manifest.backup`;
  `BACKUP_VERSION = 2` (миграция v1 → v2).
- `writer.updateTrackSources` / `addTracks` пересчитывают `track.pluginId`
  из `sources[0]`.
- `MetadataService.invokeApplyCandidate` проверяет `isDisconnected`.
- `MetadataMenu`: убран `issuesCount`, после `search()` — тост «Найдено N».

### Fixed

- Дубликаты `root_track` / `track1` при сканировании.
- `track.pluginId` не обновлялся при `updateTrackSources`.
- `CoverBlobCache` удалён (`useAlbumCover` читает только `Album.coverBlob`).
- `zvuk.applyCandidate` вызывался у отключённого плагина.
- Legacy-ключи `yandex`/`yandex-self` в бэкапе → в `manifest.backup`.
- `FOLDER NOT FOUND` в `ScanQueue`.
- Race в `setLibrary` (убран `withWriteLock`).

### Removed

- `CoverBlobCache`, `writer/mutex`, `ZVUK_PLUGIN_ID` из `resolve.ts`,
  `PLUGIN_STORAGE_KEYS` из `BackupService`, `DEFAULT_METADATA_PROVIDER_ORDER`,
  общий `TrackMetadataService.fetch`, Jaro-Winkler из `PlaylistMatcher`.

### Internal

- `vue-draggable-plus`; `normalizeMatchString` (NFC + trim + lowercase);
  обновлены спеки и E2E (`06`, `08`, `05`, `12`).

## [0.16.1] — Стабильная склейка и Кандидаты

Хотфикс к 0.16.0: симметричная склейка, кандидаты вместо дубликатов, управление
альтернативными источниками из меню трека.

### Added

- `TrackCandidatesModal` + пункт «Найденные варианты» в `TrackActions`.
- `mergeWithTrackId` в `MetadataCandidate.extMetadata` — ссылка на «хозяина»
  при `merged-soft`.

### Changed

- `findBestMatch` — симметричный fuzzy (сортировка по длине), без штрафа
  `* 0.4`; порог `0.75` пропускает похожие названия как кандидатов.
- `merge` при `merged-soft` создаёт новый трек (вместо добавления candidate
  в `bestMatch`).
- `applyCandidate` при `mergeWithTrackId` мержит треки (sources, плейлисты,
  история, дизлайки).
- `MetadataCandidatesModal.onApply` вызывает `metadataService.applyCandidate`.
- У стриминговых треков снова доступны «Найти в интернете» и «Редактировать
  вручную»; «Удалить метаданные» скрыто.
- `restoreFromCache` (yandex) возвращает `null` при `pending`/`error` папках.
- `loadImpl` — имя корня из манифеста.
- `ScanQueue.cancelAll` сбрасывает `scanning` в `error`.
- `playAll` в `FolderList` обходит поддерево, тост при пустом результате.
- `playAt` при пустых `sources` — авто-восстановление через провайдеров.
- `library.tracksByArtist` используется в `recordPlay`/`dislike`.
- `deepToRaw` вынесен в `src/utils`; `AlbumService` — debounce 500 мс;
  `ToastService` очищает таймеры вытесненных тостов; `getPageTitle` берёт имя
  альбома из контекста.
- `playerRestore` восстанавливает `wasPlaying`; `recordPlay` не вызывается
  при восстановлении.
- `apiClient.fetch` — `credentials: 'include'` по умолчанию.
- `activatePlugin` без reload, `router.push('/')`.
- `SCHEMA_VERSION = 9` (сброс IDB).

### Fixed

- Дубли папок при force scan; UI залипал на «Синхронизация...»; force scan
  удалял треки; `error` перезаписывался на `scanned`.
- Трек пропадал из папки при склейке.
- Обложка в `NowPlayingInfo` и `TrackCover` (`album.coverBlob` первичен).
- «Найти в Звуке» — обложка через `metadataService.applyRemote`.
- `Song (Remaster)` / `Track 2` не strict.
- `activeTab` в `SettingsView` из хэша.
- `FolderSyncMenu` без `any`.

### Internal

- `useAppBootstrap`: `isBootstrapping = false` сразу после `library.restore`,
  фоновые задачи — асинхронно; E2E `14`, `06`, `07`, `09`, `02`;
  юнит-тесты `TrackMerger`, `PlaylistMatcher`.

## [0.16.0] — 2026-11-04

Стабильная синхронизация, blob-обложки, чистка легаси.

### Added

- Blob-обложки из ID3 (`Album.coverBlob` первичен, `coverUrl` вторичен);
  `CoverImage` принимает `albumId`; `useAlbumCover` резолвит blob URL.
- `wasPlaying` в `PersistedPlayback`; `isRestoring` в `usePlayerStore`.
- `cleanupSubtree` в `setLibrary` — force scan удаляет отсутствующее атомарно.
- Кнопка «Попробовать ещё раз» в `RadioCatalog` / `PodcastCatalog`.

### Changed

- `urlPath` для корня — `''`; убран `disk:/` из fallback `remotePath`.
- `FolderScanState` — единственный источник правды (`FolderStatusService`
  удалён).
- `scanAll` при ошибке `listResources` помечает папку `error` до `try`.
- `ScanQueue.isRunning` — `ref`; `useFolderSync` опрашивает периодически.
- `restoreFromCache` (yandex) возвращает `null` при `pending`/`error`.
- `apiClient.fetch` — `credentials: 'include'`; `YandexDiskService` /
  `YandexSelfService` через `apiClient.fetch`.
- `activatePlugin` без reload.
- `RadioFilters` компактнее; `CatalogLayout#filters` — `max-h-[40vh]` на мобилке.
- `SCHEMA_VERSION = 8`.

### Fixed

- Дубли папок при force scan; UI залипал на «Синхронизация...»; force scan
  удалял треки; `error` перезаписывался на `scanned`.
- `pdf`/`epub`-заглушки, `ModalHost` focus.

### Removed

- `FolderStatusService`, `folders/types.ts`, `player:folderStatuses`,
  `disk:/` fallback, `any` в `useFolderSync`.

### Internal

- `TrackMerger/apply` — sync, возвращает `pluginIds`; `saveCachesForPlugins`
  отдельно; `metadata.worker` — `coverBlob: Blob | null`; обновлены E2E `07`,
  `09`, `14`.
