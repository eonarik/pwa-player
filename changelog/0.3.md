# Changelog 0.3.x

> Релизы: 0.3.2, 0.3.1, 0.3.0

## [0.3.2] — 2026-10-04

### Security

- `AUTH_SECRET` — падение в production без секрета; `timingSafeEqual`;
  `express.json({ limit: '1mb' })`.

### Added

- `flush()` в `playlists`/`history`/`dislikes`/`uiSettings` для синхронизации
  при `beforeunload`/`visibilitychange`; `UNKNOWN_ARTIST_PLACEHOLDER`.

### Changed

- Дебаунс сохранения в сторах (300–500 мс); LRU-кеш `dominantColor`;
  `useDominantColor` в `try/catch`; очистка истёкших `not-found`;
  упрощены `hasNext`/`hasPrev`; `shuffleArray` (Fisher-Yates);
  `UNKNOWN_ARTIST_PLACEHOLDER = ''`; `ModalOptions.type` без `custom`;
  Prettier; комментарии в `server/src`.

### Fixed

- Shuffle при запуске папки/плейлиста/альбома; `toggleShuffle` во время
  воспроизведения; `next`/`prev` при shuffle; дизлайки после перезагрузки;
  кэш метаданных при падении обоих API; кэш настроек после `PUT /text`.

### Removed

- Дубли `UNKNOWN_ARTIST_PLACEHOLDER`.

## [0.3.1] — 2026-10-04

### Added

- `normalizeClientPath` (нейтральный модуль); negative cache в `loadSettings`;
  `isSettingsPath`; тесты на сервере (`vitest` projects); `fuzzball`;
  `safeTokenSetRatio`/`safeTokenSortRatio`.

### Changed

- `resolveDiskPath` нормализует `..` (закрыт path traversal); `isPathPublic`
  нормализует и разрешает родителя публичной папки; `metadataSimilarity`
  переписана на token-based (0.8/0.2 в пользу title, штраф 0.5 при разном
  артисте, транслит); `vitest.config.ts` без `mergeConfig`; `fuzzball`
  в `server/package.json`.

### Fixed

- Path traversal; шум метаданных (`Radiohead` vs `Иван Кучин`).

### Removed

- `src/metadata/jaroWinkler.js` (перенесён на сервер).

### Планируется

- `AUTH_SECRET` падать в production; `express.json` 1mb; не кэшировать пустой
  результат при падении обеих API; инвалидация кэша настроек после `PUT /text`;
  `.ts`-артефакты в комментариях `server/src`.

## [0.3.0] — 2026-10-03

### Added

- `TrackRow` (общая база), `BatchDownloadButton`, `MetadataApplier`,
  `MetadataFetchResult`, `DropdownMenu`/`useMenu`, `menu.ts` + `AppDrawer` +
  `getPageTitle`, `pluginCanDownload`/`manifest.canDownload`, `pluralize`,
  `FolderBreadcrumbs`, параллельный обход подпапок в `refreshSubtree`,
  `FolderStatus` в `FolderList`.

### Changed

- SVG — в компонентах; `FolderView` в `src/views/`; `recalcUpwards`
  переписан; `addTracks`/`updateFolder` вызывают `recalcUpwards`;
  `setLibrary`/`removeBySource`/`removeFolders` сбрасывают `currentFolderId`;
  Яндекс.Диск: `sourceId` ≠ `folderId`; `SCHEMA_VERSION = 3`;
  `useMediaSession` с `immediate: true`; `useKeyboardShortcuts` блокируется
  модалкой; `normalizeUmlauts` сохраняет регистр; `FullPlayer`-анимация
  в `App.vue`; `TrackRow.track` — `Track | LibraryTrack`; README; версии
  фронт/сервер `0.3.0`.

### Fixed

- `.app-safe-bottom` (`safe-area-inset-top`); `BatchDownloadButton` в локальной
  папке; дубликат тостов при подключении Диска; сортировка в `recalcUpwards`;
  мёртвые импорты; `Breadcrumbs` → `FolderBreadcrumbs`; `Transition` без
  `v-if` в `FullPlayer`.

### Removed

- `useDownloadOrchestrator.ts`, `FolderDownloadButton.vue`,
  `PlaylistDownloadButton.vue`, `LocalSettings.vue`, пустой
  `local/collect.ts`.
