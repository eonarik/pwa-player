# Changelog 0.8.x

> Релизы: 0.8.3, 0.8.2, 0.8.1, 0.8.0

## [0.8.3] — 2026-10-22

### Added

- Настройки радио: «Очистить кеш радио».
- Кеш стран/тегов Radio Browser (24 ч) и топа/поиска (5 мин) с fallback
  на stale; баннеры «Сервер недоступен» / «Фильтры не дали результатов».
- Кеш `searchQuery`.
- Единый список топ+поиск; разделение `▶`/`+`/`X`; подсветка играющей станции;
  сворачиваемые фильтры на мобилке.
- `QueueView` → «В плейлист».
- `SectionTitle`, `CoverImage`, `NowPlayingInfo`.

### Changed

- `RadioService.searchByName` — `order`, `{ stations, total }`, `limit * 3`.
- `RadioService.getTopStations` — кеш с fallback.
- `RadioBrowserClient` — soft-TTL.
- `radio/manifest.ts` — чистка кеша + `getSettings`.
- `PlayerControls`/`useMediaSession`/`useKeyboardShortcuts`/`AudioService` —
  no-op для live.
- `AudioService.play` — отладочный лог только в DEV.
- `PlayerControls`/`FullPlayer` — `CoverImage` с fallback.

### Fixed

- Live в избранном/дизлайках/плейлистах; «Очистить» в `HomeView`;
  `searchQuery` после F5; пустой список при фильтрах; кнопка «Играть»
  без сохранения; индикатор играющей станции; битая обложка; изоляция тестов
  `RadioBrowserClient`.

## [0.8.2] — 2026-10-22

Технический релиз: рефакторинг, разбиение крупных файлов, устранение
дублирования. Без новых пользовательских функций.

### Changed

- `AudioService`: динамический импорт `hls.js`, `load` async.
- `SettingsView`: `getAllSettingsSchemas` (учитывает `extension.getSettings`).
- `PlayerControls`/`useMediaSession`/`useKeyboardShortcuts` — no-op для live.

### Fixed

- Live в избранном/дизлайках/плейлистах; `HomeView` «Очистить»;
  `SettingsView.resetAll` чистит `localStorage`; `RadioView.removeStation`
  через `modalService`; отладочный лог в `AudioService.play`; тест HLS.

### Added

- «Радио» в шторке меню; `getPageTitle` для radio; `createPlaylistFromImport`
  распознаёт `http(s)://` как радио.

### Removed

- Дубли `isAudioFile`, `resolveDiskPath`/`toClientPath`, `mapWithConcurrency`,
  `getPluginName`/`getPluginManifest`, прямые `fetch` Radio Browser.
- Разбиты `createPlugin.ts`, `scan.ts`, `player.ts`, `FolderView.vue`,
  `PlaylistRoute.vue`, `SettingsView.vue`, `RadioView.vue`.

## [0.8.1] — 2026-10-21

### Fixed

- Добавленные станции не видны сразу (`addAndPlay` → `saved` + обновление).
- Счётчики станций при активных фильтрах.
- Поиск игнорировал фильтры.
- `removeStation` → `removeSavedStation`; валидация `getSavedStations`;
  `addSavedStation` возвращает `boolean`.

### Changed

- `radio/index.ts`: `disconnect` без `removeBySource`.
- `RadioService.searchByName` принимает `SearchStationsOptions`.
- `RadioView`: сортировка отдельной строкой, страна+теги в `grid`.

## [0.8.0] — 2026-10-21

### Added

- Плагин «Онлайн-Радио» (Radio Browser API), роут `/radio`.
- «Мои станции» в `localStorage`; поиск, фильтры страна/тег, сортировка,
  пагинация; счётчики станций; live-режим в плеере; HLS (`hls.js`);
  `isStateless`/`customRoute`/`hasCustomData`/`clearData`/`isLiveStream`
  в манифесте.

### Changed

- `RadioService` возвращает `{ stations, total }`; `getCountries`/`getTags`
  различают ошибку и пустой ответ; `getTopStations` — `limit * 3` и HTTPS-
  фильтр; `getTags` — `{ name, stationCount }`; `RadioView` реактивен к тегам.
- `AudioService.seek`/`seekBy`, `player.next`/`prev` — no-op для live;
  live не пишутся в историю; `artist` пустой; «Ничего не найдено» при пустом
  списке.

### Fixed

- Зависание списка, пагинация, фильтр по тегам, страны после «Повторить»,
  перезапуск live при seek/next/prev.

### Removed

- `TrackActions`/`FullPlayer` для live: метаданные, скачивание, prev/next,
  shuffle, repeat, прогресс-бар.
