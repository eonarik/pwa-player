# Changelog 0.4.x

## [0.4.0] — 2026-10-18

### Security

- OAuth Яндекс.Диска вместо JWT-пароля; токен только в серверной сессии;
  `HttpOnly`, `SameSite=Lax`; право `cloud_api:disk.app_folder`; CSRF через
  `SameSite=Lax` + `Origin`.

### Added

- Модульный монолит на бэкенде (`core/`, `plugins/`, `shared/`, `modules.js`).
- `plugins/yandex` (сессия), `plugins/feedback` (nodemailer, rate limit 1/мин).
- `v-tooltip`; `MarkdownText`; `emptyStateMessage` в манифесте.

### Changed

- `AuthService` — `me()`/`startOAuth()`/`logout()`, `credentials: 'include'`.
- `YandexDiskService` — same-origin; `connect()` — редирект на OAuth,
  `HomeView` подхватывает `?auth=ok`.
- `SCHEMA_VERSION = 4`; тултипы на всех иконочных кнопках.

### Removed

- `passport-yandex`; legacy-код в `server/src/_legacy/`.

### Fixed

- Сессия при OAuth-редиректе; `App has already been mounted` в `v-tooltip`;
  позиционирование тултипа.
