# Changelog 0.5.x

> Релизы: 0.5.1, 0.5.0

## [0.5.1] — 2026-10-22

### Added

- 3-way merge `.txt` (Логии) через `node-diff3` с маркерами конфликта.
- Табы в `SettingsView`.
- «Секретные функции» — активация скрытых плагинов.
- `isDisconnected`/`isCancelled` в `YandexSelfService`.

### Changed

- `scan.ts` — `isCancelled` прерывает фоновые процессы при отключении.
- `createPlugin.ts` — пустой пароль отличается от отмены.

### Fixed

- `Cannot read properties of undefined (reading 'tracks')` при отмене;
  вход в `yandex-self` без пароля; пути в `YandexSelfService`.

## [0.5.0] — 2026-10-21

### Added

- Плагин «Логии» (`yandex-self`).
- Базовый движок `createYandexPlugin` (общий для `yandex` и `yandex-self`).
- `YandexSelfService` (JWT + контексты); контексты в `.settings.json`;
  активация скрытых плагинов; защита от перезаписи в `TextEditorModal`;
  фильтрация в `AutocompleteInput`; количество вложенных папок в `FolderList`.

### Changed

- `ModalService` — кастомные компоненты; `createPlugin` всегда запрашивает
  код при отсутствии валидного токена; `scan.ts` — `isCancelled`.

### Fixed

- Сканирование и воспроизведение `yandex-self`; пути в `YandexSelfService`;
  реактивность списка плагинов в `HomeView`.
