# Changelog 0.15.x

> Релизы: 0.15.1, 0.15.0

## [0.15.1] — Тема «Тиффани» и Файловый менеджер

### Added

- Тема «Тиффани»: мраморный фон, витражный орнамент, брошь Play/Pause,
  `Playfair Display` / `Montserrat`.
- `FileHandlerRegistry` — ядро не знает о типах файлов; обработчики `.txt`
  и картинок.
- «Открыть локально» на главной (если плагин отключён, но файлы есть).
- `restoreFromLocalFiles`.

### Changed

- Сканер собирает не только аудио, но и файлы в `folder.files`.
- `FolderListItem` показывает прогресс «N из M» для `scanning`.
- `TextEditorModal` закрывается через `ModalService`, не зависает.
- Защита `pathMap` при синхронизации (восстановление пути по `urlPath`).

### Fixed

- Пропажа `.txt`-файлов; пустые папки с файлами; фантомная синхронизация;
  `path not found` при ручной синхронизации.

### Internal

- `createPlugin.ts` разбит на `localMatches` / `textFiles` / `localRestore`.

## [0.15.0] — Стабильный синк, Файловый менеджер и Умный локальный доступ

### Added

- `FileHandlerRegistry`: `TextEditorModal` (3-way merge), `ImagePreviewModal`,
  превью картинок в списке файлов.
- «Открыть локально» для отключённых плагинов; `restoreFromLocalFiles`.
- Прогресс сканирования в UI; причина ошибки (`reason`) в тултипе.
- E2E `09-sync-architecture`.

### Changed

- Sync 2.0: первичный скан / доскан / force scan; `ScanQueue` не дублирует
  отсканированные папки; force scan рекурсивен и перезаписывает поддерево.
- `folder.trackIds` и `folder.files` — сканер собирает всё.
- `LibraryWriter.setLibrary` — мьютекс против гонок.
- `uiSettings` — обратно на `localStorage`.
- Автопоиск пропускает стриминг/подкасты/радио.
- `applyPatch` не перезаписывает `artist`/`title` при `hasMetadataEdits`.

### Fixed

- Yandex Self: пути без `disk:/`; сопоставление локальных файлов с облачными
  (`disk:`-префикс); `.txt` в начале имени; пустые папки; фантомная
  синхронизация; `TextEditorModal`; приоритет обложки; сброс метаданных
  без `raw`.

### Removed

- `radio-browser-api`; хардкод кодов активации; `getTextFiles`.
