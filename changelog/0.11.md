# Changelog 0.11.x

> Релизы: 0.11.4, 0.11.3, 0.11.2, 0.11.1, 0.11.0

## [0.11.4] — 2026-11-25

### Added

- `alternateSources` при fuzzy-мэтчинге ниже strict; UI для разрешения
  конфликтов (бейдж + модалка).
- `AlbumService` (IDB `player:albums`).
- Фоллбэк для артистов (имя папки → «Неизвестный исполнитель»).

### Changed

- Порог мэтчинга — `uiSettings.playlistMatchThreshold`.
- Обложки убраны из `raw`; при мэтчинге переносятся только в `Album`.
- `MetadataService`: убраны `applyCandidate`/`'issue'`, неуверенные — в
  `alternateSources`.
- Коллекции хранят только `trackId`; `TrackCover` берёт из `Album`.

### Fixed

- Потеря обложек после F5; потеря артистов; `DataCloneError`; `ModalHost`
  focus; бесконечные ретраи; `resetAll`; `FolderFilters` `Divider`;
  переход в плагин после подключения.

### Removed

- `TrackSnapshot`, `useResolvedTracks`, `usePlaylistRematch`,
  `MetadataIssuesModal`, логика `issues`.

## [0.11.3] — 2026-11-20

### Added

- Мультиисточниковые треки (`sources[]`) с фоллбэком.
- Умный мэтчинг (`resolveOrCreateTrack`) при добавлении/импорте.
- `ReconciliationService` — фоновое дотягивание совпадений.
- Сущность «Альбом»; фильтр «Только с альбомами»; fuzzy-поиск артистов;
  `AppLoader` + версия/хэш билда.

### Changed

- Единый источник правды — `libraryStore`, коллекции хранят `trackIds`.
- `ArtistsView` — список; `AlbumView` — `TrackListPage`.
- `SCHEMA_VERSION = 5`; `PluginManifest.sourcePriority`
  (local 10 / cloud 20 / streaming 30).
- `createYandexPlugin` без `isSelf`; сессии на `session-file-store`.

### Fixed

- Дубликаты треков; пустые альбомы; затирание обложек; `DataCloneError`;
  `resetAll`; настройки плагинов после сброса; `runAutoFetch` при полных
  метаданных; ошибки `YandexSelfService`; `TrackCover`; `ModalHost` focus;
  `checkSession`.

### Removed

- `TrackSnapshot` и утилиты, `useResolvedTracks`, `usePlaylistRematch`,
  миграции коллекций, `PlaylistToolbar`, `PlaylistContent`, `QueueTrackRow`.

## [0.11.2] — 2026-11-10

### Added

- `AppLoader` (спиннер + фразы) и встроенный лоадер в `index.html`.
- Версия и хэш билда в углу экрана.
- «Тихое отключение» при мёртвой сессии без очистки кеша; «Офлайн»-статус.
- «Открыть локально» без авторизации; повторное подключение без сканирования.
- Индикация ошибки сканирования с кнопкой «Обновить»; бейдж «Стрим».
- Подсказки в настройках о стриминге; `runAutoFetch` вынесен в сервис.

### Changed

- `App.vue` → `useAppBootstrap` / `useAutoActions` / `useDocumentTitle` /
  `useTrackEndOnVisibility`.
- `HomeView` → `usePluginsList` / `usePluginActions` / `PluginCard`.
- `TrackListPage`: `customSelect`, `itemKey`; `QueueView` на `TrackListPage`.
- `AppDrawer` — скролл + `safe-area-inset-bottom`.
- `usePwaUpdate` починен; кнопка «Проверить обновления» в настройках.
- `FileLocationFilter` скрывается при однотипных треках.
- Сессии — `session-file-store`.

### Fixed

- CORS в Радио (HLS-прокси); рекурсия ретраев; `null` в ответах Звука;
  «Открыть» при пустом кеше; переход после подключения; отмена `checkSession`;
  `AbortError`; пустой экран.

### Removed

- `PlaylistToolbar`, `PlaylistContent`, `QueueTrackRow`, старая панель поиска
  плейлиста.

## [0.11.1] — 2026-11-03

### Added

- `createTrackSnapshot`, `useResolvedTracks`.
- Автосканирование папки скачивания; `processedTracks` против рекурсии
  автопоиска.

### Changed

- Единый `TrackSnapshot`; `PersistedTrack` (алиасы в плагинах).
- `yandex-self`: сессии вместо JWT, JWT/токены удалены.
- `Track.filename`/`album` опциональны.

### Fixed

- Стриминговые треки в истории/дизлайках; скачанные треки; тесты `yandex-self`.

## [0.11.0] — 2026-11-03

### Added

- Плагин «СберЗвук»: поиск (треки/артисты/альбомы), умный поиск по артисту,
  плейлисты/избранное/дизлайки, воспроизведение через прокси.
- `isStreaming`, `order` в `PluginManifest`; картинки в иконках плагинов.
- `duration`/`coverUrl` в `PlaylistTrackSnapshot`; `hasId3Tags`.

### Changed

- Приоритеты метаданных: manual > file > auto > filename.
- `MetadataService` — снимок `raw` для сброса.
- Автопоиск не для стриминга и не при `metaSource = 'file'|'manual'`.
- `PlaylistRoute` собирает треки из library/виртуальных снимков.
- `HomeView` сортирует по `order`; бэкенд-плагин `zvuk`.

### Fixed

- `fetch failed` при скачивании (ретраи/таймауты); иконки в теме Барби;
  фантомное подключение после сброса.

### Removed

- Упоминания `sberzvuk-api` — локальный `sberzvuk-api.js`.
