# Changelog 0.9.x

## [0.9.0] — 2026-10-22

### Added

- Плагин «Подкасты» (Apple Podcasts): каталог, поиск, подписки, страница
  подкаста, «Играть всё».
- Прокси RSS/iTunes на бэкенде.
- `contentKind: 'linear'` — ядро скрывает shuffle/repeat/dislike/favorite.
- `AddRemoveButton`, `CatalogLayout`, `useSoftTtlCache`, `CoverImage`,
  `NowPlayingInfo`, `SectionTitle`.
- `QueueView` → «В плейлист».
- Индикация играющей станции в каталоге радио; сворачиваемые фильтры на мобилке.

### Changed

- `RadioService`/`PodcastStorage` на soft-TTL с fallback на stale.
- `RadioService.searchByName` — `order`, `{ stations, total }`, `limit * 3`.
- `RadioBrowserClient` — soft-TTL кеш стран/тегов.
- `RadioCatalog`/`PodcastCatalog` на `CatalogLayout`/`AddRemoveButton`.
- `PlayerControls`/`FullPlayer` скрывают shuffle/repeat/reaction для linear.
- `TrackActions` скрывает метаданные/плейлист/скачивание для linear.
- `useMediaSession`/`useKeyboardShortcuts` — no-op для live.
- `AudioService.seek`/`seekBy` — no-op для live.
- `SettingsView` разбит на табы; `getAllSettingsSchemas`.
- `homeView` «Очистить» только при `hasCustomData()`.
- `radio/manifest.ts` чистит кеш, `getSettings` с действием «Очистить кеш».

### Fixed

- Live в избранном/дизлайках/плейлистах; `PlayerControls` для live;
  кеш радио/подкастов; `searchQuery` после F5; пустой список при фильтрах;
  кнопка «Играть» в каталоге; битая обложка; изоляция тестов
  `RadioBrowserClient`; лимит прокси подкастов 30 МБ.

### Removed

- Дубли `readCache`/`writeCache`, кнопок `+`/`X`, шапки/пагинации,
  «обложка + название».
