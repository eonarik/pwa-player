# Changelog 0.19.x

> Релизы: 0.19.0, 0.19.1, 0.19.2, 0.19.3, 0.19.4

## [0.19.4] - 2026-11-18

### Added

- **[CUEI-0019] Проксирование API Радио (Radio Browser).** Клиент больше не ходит напрямую на `de1.api.radio-browser.info` (обход блокировок провайдеров, CORS).
  - Серверный прокси `server/src/plugins/radio/routes.js` (проброс GET-запросов).
  - `server/src/modules.js` монтирует `/api/radio-browser`.
  - Клиентский `src/plugins/radio/browser/api.ts` использует `API_BASE = '/api/radio-browser'`, убран заголовок `User-Agent` (браузеры не позволяют его переопределять).
- **Радио: мобильная адаптация (свайп-карусель).**
  - `RadioView.vue`: переход между «Сохранёнными» и «Каталогом» через свайп (`useSwipe` из `@vueuse/core`) и точки-индикатор.
  - `CatalogLayout.vue`: на мобильном фильтры скрыты в `BottomSheet` (шторка снизу с кнопкой «Применить»), убрано вложенное скроллирование `max-h-[40vh]`. Кнопка «Фильтры» в шапке с бейджем количества активных фильтров.
  - `CatalogLayout.vue`: пагинация «Назад/Вперёд» заменена на кнопку «Показать ещё» (infinite scroll / подгрузка), которая закреплена внизу экрана и не скроллится вместе с контентом.
  - `AddRemoveButton.vue`: увеличены тач-таргеты (`!p-2`, 40x40px) для удобного нажатия на мобильных.
  - `RadioCatalog.vue`: кнопки play/add увеличены на мобильных, добавлен проп `isMobile`, поддержан `offset` при поиске.

### Changed

- `RadioService.searchByName` принимает `offset` в опциях, чтобы работала пагинация при поиске (раньше `offset` был жестко зашит в `0`).
- `CatalogLayout` теперь принимает `isMobile` и `activeFiltersCount`, а также эмитит `load-more` вместо `prev`/`next`.
- В `RadioView.vue` на мобильных всегда видна кнопка «Добавить станции» (на десктопе тоже), а при возврате на первый экран сбрасывается `pageIndex`.
- `changelog/0.19.md` и `docs/STRUCTURE.md` обновлены.

### Fixed

- **Десктопная верстка радио.** Исправлен баг, при котором на десктопе (без свайпа) обе страницы рендерились рядом в две колонки из-за `w-[200%]` и `w-1/2`. Для десктопа карусель отключена, экраны переключаются через `v-if`/`v-else`.
- **Мобильная верстка радио.** Исправлено разъезжание экранов при свайпе: контейнер `w-full`, дети `w-full shrink-0`, сдвиг на `-100%` за шаг (как в Логиях).

## [0.19.3] - 2026-11-18

### Added

- **[CUEI-0024] Логии: режим редактирования (переключатель).** Toggle в шапке
  панели Логий (`LogiiPanelHeader`, рядом с кнопкой refresh) включает/выключает
  доступность всех create/update/delete операций. Флаг персистентен — хранится
  в `localStorage` под ключом `logii:editMode`.
  - Новый composable `useEditMode.ts` — единый источник истины для флага.
  - Скрыты при выключенном режиме: «Добавить автора», «Создать топы»,
    переименование/удаление авторов и топов (hover-кнопки), загрузка треков,
    «Найти в стримингах», удаление треков, редактирование vibe,
    редактирование/удаление комментариев, загрузка/удаление картинок.
  - Play-кнопки, навигация, отправка нового комментария — доступны всегда.
- **[CUEI-0010] Адаптация Логий под мобильные (карусель-пейджер).**
  - 3 страницы: Авторы → Папки → Контент. Навигация через `translateX` +
    горизонтальный свайп. `useLogiiPager` — переходы вперёд/назад с fallback
    (prev → следующий слой; goNext → предыдущий; intro-сброс при смене
    автора/папки).
  - Точки-индикатор внизу (3 шт, активная подсвечена), тап по точке ведёт
    на соответствующий слой.
  - `useLogiiAutoSelect` — автовыбор автора/папки отключён на мобильном
    (иначе свайп-навигация теряет смысл).
  - `useMediaQuery` (общий composable, `src/composables/`) — реактивный
    `window.matchMedia(query).matches` с подпиской/подпиской на `change`.
  - `useSwipe` (общий composable) — горизонтальный свайп без preview,
    вертикальный скролл не блокируется (`touch-action: pan-y`).
  - Хедер (`LogiiPanelHeader`) переработан: единый для десктопа и мобильного,
    хлебные крошки, кнопка «Назад» (goPrev → goParent fallback).
  - `LogiiPanel` — табы (Трек/Галерея) переехали внутрь панели; на мобильном
    таб-кнопки на всю ширину.
  - `LogiiAuthorsColumn`/`LogiiFoldersColumn` — при `isMobile` занимают всю
    ширину страницы карусели; на мобильном collapse-стрелка скрыта.
  - `LogiiAuthorRow` — при `isMobile && isEditMode` кнопки pencil/trash
    рендерятся inline в строке (без hover/Teleport).
  - `LogiiFoldersColumn` — при `isMobile && isEditMode` кнопки pencil/trash
    рендерятся inline в строке (без hover/Teleport).

### Changed

- `useEditMode` — возвращает `Ref<boolean>` вместо `ReturnType<typeof ref<boolean>>`.
- `LogiiView` — вся разметка переработана: карусель с `transform: translateX`,
  fallback-свойства для превью соседних страниц (`effectiveFolders`,
  `mobileFallbackAuthor`, `effectiveAuthorName` и т.д.).

### Tests

## [0.19.2] - 2026-11-13

### Added

- **[CUEI-0011] Логии: объединённый вид трека.** Текст (vibe) и комментарии
  рендерятся в одном табе «Трек» — переключение «трек»/«чат» убрано.
  Табы: «Трек» | «Галерея». Никнейм переехал вниз к полю ввода.
- **[CUEI-0012] Логии: уведомления об изменениях файлов.**
  - `FolderFile` получил `modified`/`size`; скан yandex-self наполняет их
    для всех файлов, включая аудио (`fileExcludeKinds: []`).
  - Итеративный diff во время скана через колбэки `ScanProgressCallback`:
    `onAfterFileScan` (каждый файл → added/modified),
    `onAfterFolderScan` (все файлы папки → removed на уровне),
    `onAfterSubtreeScan` (вся ветка).
  - `useLogiiChanges`: снимок сезона в IndexedDB (`logii:snapshot:<path>`),
    `initScan` (prev snapshot + очищение состояния), `finalizeScan`
    (запись нового снимка из `scannedFilesMap`), первый снимок молча.
  - Колокольчик с бейджом непрочитанных и панель событий в шапке Логий;
    клик по событию ведёт в папку файла, кнопка «Очистить» сбрасывает.
    События сортируются по `modified` (новые первыми, без `modified` — в конец).
    Фолбэк: если у prev-записи `modified === null` (старые снимки без поля),
    сравнение `modified` пропускается, чтобы не спамить ложными «изменено».
  - Типы событий: файл добавлен, файл изменён, файл удалён.
- **[CUEI-0005] Логии: поиск в стриминговых провайдерах.**
  - Контракт `LibrarySource.searchTracks?(query)` / `fetchAudioBlob?(candidate)`
    и хелпер `searchStreams` — ядро опрашивает реестр по контракту,
    конкретных плагинов не знает.
  - Плагин zvuk реализует обе методы (поиск + `/api/zvuk/stream`).
  - Кнопка «Найти в стримингах» рядом с загрузкой трека: модалка поиска,
    скачивание кандидата и перенос физическим файлом в папку Логий
    (`uploadFile` + force-скан). Лимит 30 МБ, дедуп имён файлов.
- **[CUEI-0006] Логии: кнопки редактирования/удаления «мячиками».**
  У авторов (`LogiiAuthorRow`) и топов (`LogiiFoldersColumn`) кнопки
  pencil/trash скрыты (`translate-x-full opacity-0`) и по очереди выезжают
  справа при hover строки: pencil без задержки, trash с `delay-75`
  (`transition-all duration-200 ease-out`, `origin-right`).
  `data-testid` кнопок сохранены. Teleport в `body` для позиционирования `fixed`.
- **[CUEI-0009] Логии: два состояния подсветки — навигация и playback.**
  - Авторы: «играет трек автора» (`isAuthorCurrent`) — фон `bg-active/10`,
    «автор открыт в навигации» (`isNavigated`) — левая граница
    `border-l-2 border-active`.
  - Топы: «топ открыт» (`currentFolderName`) — фон `bg-active/10`,
    «в топе играет трек» (`isTopPlaying`) — левая граница
    `border-l-2 border-active`.

### Tests

- Юнит: `diffSnapshots` (6 сценариев diff снимков), `candidateFileName`
  (формат имени, санитизация, фолбэки, дедуп).
- E2E: `20-logii-changes` — реальные diff-события через force-скан с колбэками
  (`modified`, `removed`), `21-logii-stream-search` (модалка);
  существующие Логия-спеки переведены на табы Трек|Галерея.

### Changed

- **Скан: снижение concurrency** `mapWithConcurrency` 5 → 2 (`scan.ts`)
  для снижения нагрузки на Яндекс API.
- **Логии: сетевые триггеры скана отключены**. `runFullCheck`,
  `triggerSync`, `onMounted(runFullCheck)`, `watch(authorName|folderName)` —
  закомментированы в `LogiiView.vue`. Уведомления генерируются только при
  ручном refresh (кнопка ↻).
- **Diff по уровням дерева**: `ScanProgressCallback` получил колбэки
  `onAfterFileScan` (каждый файл), `onAfterFolderScan` (все файлы папки),
  `onAfterSubtreeScan` (вся ветка). `useLogiiChanges.initScan/onAfterFileScan/
onAfterFolderScan/finalizeScan/readPrevSnapshot` реализуют итеративный diff
  added/modified/removed во время скана без ожидания полного snapshot.
- `ScanFolderOptions` принимает `onAfterFileScan`/`onAfterFolderScan`;
  `LogiiRefreshDeps` принимает полный набор методов `changes` (initScan/
  finalizeScan/applyScanResult/seasonUrlPath) — refresh теперь тоже считает diff.

### Fixed

- **[CUEI-0022] Колокольчик: штатные удаления и переименования больше не
  дают событий.** `markPendingDelete`/`markPendingMove` отмечают urlPath при
  удалении/переименовании. `onAfterFileScan`/`onAfterFolderScan`/`finalizeScan`
  подавляют removed для помеченных путей и их потомков; `diffSnapshots` и
  `processSnapshot` учитывают отметки. `pendingLocalDeletes.clear()` вызывается
  только после успешного обновления снимка.
- **Ложные `removed` для аудио-файлов.** `onAfterFolderScan` использует
  `scannedUrlPathsInRun` (наполняется в `onAfterFileScan` для всех файлов,
  включая аудио) вместо `scannedSet` из `folderFiles` (содержал только non-audio).
- **Уведомления не спамятся на первом скане.** `hasPrevFiles` флаг в `initScan`
  проверяет `lastScan` в IDB — если скан ещё не выполнялся, `added`/`modified`
  блокируются.
- **[CUEI-0023] Race-условие при быстром переключении папок.** `useLogiiTrack`
  инкрементирует `requestId` на каждый `reload()`; устаревший ответ (от
  предыдущей папки) отбрасывается через `if (thisRequest !== requestId) return`.
- **Регресс resume-скана (`fileExcludeKinds`)**: при `skipScanned` уже
  `scanned`-папки больше не попадают в снимок с пустым `files: []` и не затирают
  содержимое в библиотеке (исчезали intro-файлы и картинки после входа в Логии).
  Двойная защита: `scan.ts` пропускает такие папки до push в снимок,
  `setFolders` игнорирует пустой `files` у `scanned`-папок из снимка.

## [0.19.1] - 2026-11-13

### Fixed

- `shouldSkipAuto` больше не скипает скачивающийся трек: берёт реальное состояние из `DownloadOrchestrator` вместо литерала `false`.
- При истёкшей сессии облачного источника плеер пробует следующие источники трека (streaming/local), а не останавливается после первого AuthError.
- Ошибка авторизации предлагает подключить именно упавший плагин, а не первый в списке или arbitrary sources[0].
- Восстановление воспроизведения после перезагрузки: перебираются все источники по приоритету; если все недоступны — переход к следующему треку, а не «залипание» на мёртвом.
- Во время восстановления ошибки аудио больше не вызывают пропуск трека до взаимодействия пользователя.
- Local-плагин: повторное подключение уже добавленной папки не создаёт дубль и не падает.
- «Открыть» для local при нескольких корнях ведёт навигацию, а не молча выбирает первую папку.
- «Обновить с облака» при отключённом источнике перехватывает отмену и OAuth-редирект пользователем без сообщения об ошибке; статус подключения обновляется сразу.
- «Обновить с устройства» сканирует только текущий источник, а не все плагины разом.
- Меню действий папки не рендерится, когда папка не выбрана.

## [0.19.0] - 2026-11-13

### Added

- **Storybook приведён в рабочее состояние** (10.6.3): собрано 40+ историй, ни одна
  не падает при монтировании и не схлопывается в пустоту.
- **37 stories-файлов**: 14 атомов (`Atoms/*`), 17 молекул (`Molecules/*`),
  `Atoms/IconGallery` (сетка всех 48 иконок реестра `ICONS`) и 4 органима как
  исключение для singleton-host'ов без props (`ToastHost`, `ModalHost`) плюс
  тематические компоненты (`Themed/TrackCover`, `Themed/CoverImage`).
- **Темы в Storybook**: каждая история открывается в 5 темах (cuei default / radio /
  neon / barbie / tiffany) переключателем в тулбаре; темы применяются изолированно,
  без протекания между стори.
- **Decorator `withThemeGrid`**: сетка 5 копий одной истории рядом с подписями тем —
  прямое сравнение вариантов отображения. Показывается только при выборе cuei (default).
- **Decorator `withThemedChrome`**: каркас `header`/`main`/`footer` с классами тем —
  нужен компонентам, чьи стили объявлены как `.theme-x .component { ... }`.
- **Линтер-границы слоёв** (`eslint.config.ts`, блоки `app/ui-layer-atoms` /
  `app/ui-layer-molecules`): атомы и молекулы не могут импортировать сторы, сервисы,
  плагины и компоненты вышестоящих слоёв — зависимость только вниз.
- `docs/storybook.md`: карта слоёв, таблица запретов по слоям, механика тем и её
  ограничения (teleport-компоненты), правила написания stories, зона вне объёма.
- Секция «UI-слои» в `docs/conventions.md` со ссылкой на `docs/storybook.md`.
- Ветка `todo` в `ROADMAP.md`: Storybook для виджетов плагинов (BandPlayerWidget,
  YandexLoginGate) — требует моков `audioService` и сторов.

- **Структура компонентов**: `src/components/ui/` разделён на три слоя.
  - `atoms/` (14): Button, IconButton, LinkButton, Input, Textarea, Select,
    Checkbox, Toggle, Label, Icon, Divider, Spinner, Badge, PlayingIndicator.
  - `molecules/` (17): InputWithAffix, SearchInput, AutocompleteInput, FormField,
    ListRow, ListContainer, Toolbar, PageHeader, SectionTitle, EmptyState,

  - `ui/` — органимы: связанные с доменом и/или обращающиеся к стору
    (TrackCover, CoverImage, ModalHost, ToastHost, VirtualGrid, MarkdownText и др.).
  - Классификация по признаку «знает про стор», а не по тематическим CSS-классам:
    `PlayingIndicator` — атом, `TrackCover` — органим.
  - Переезд файлов, обновление ~240 импортов и относительных путей внутри
    компонентов (`../icon` → `../../icon`). Схемы данных и API плагинов не затронуты.
- `.storybook/main.ts`: убраны аддоны, несуществующие в Storybook 10 (`addon-essentials`,
  `addon-interactions`, `addon-a11y`) — сборка падала с `Cannot find module`;

  выбранная тема протекала на все последующие стори.
- Удалён дубль `ui/CoverPicker.vue` — пиксель-в-пиксель копия `library/CoverPicker.vue`,
  ниоткуда не импортировался. Единственный экземпляр - `molecules/CoverPicker.vue`.
- Старые stories вне концепции атомы/молекула удалены: `player/PlayerControls`,
  `player/PlayerProgressBar`, `library/FolderSettingsMenu`, `icons/Icons`

- `AGENTS.md` (корень воркспейса): путь к документации исправлен с `/docs` на
  `cuei-media-player/docs/`.
- `eslint` и `.gitignore` учитывают артефакт `storybook-static/`.

### Docs

- Тема `barbie` перестала быть мёртвой: раньше CSS-файл существовал и выбор был в
  тулбаре тем, но правил `.theme-barbie-*` не было ни в одном компоненте. Теперь
  они заданы в 8 местах (Button, IconButton, ListRow, ModalLayout, DropdownMenu,
  ToastHost, ViewToggle, SettingsActionRow); радиус кнопок через `--radius-btn: 9999px`.
- Конверты `tiffany` применены там же, где уже были `neon`/`radio`; правки помечены
  комментарием о происхождении, значения конвертов не изменялись.
- `PlayingIndicator` в теме `neon` использует жёлтый акцент вместо розового: элемент
  лежит в левой колонке рядом с красным сердцем «избранного» и сливался с ним по цвету.
- Механика тем и её ограничения (teleport-компоненты, тема через тулбар) задокументированы
  в `docs/storybook.md`; отдельного файла с описанием тем в проекте нет.
- `docs/STRUCTURE.md` перегенерирован (`yarn tree-generate`).

### Fixed

- **Button / IconButton в Storybook**: у `meta` не было `render`, а обязательный
  контент (slot-текст у Button, `icon` у IconButton) задавался только внутри
  отдельных историй. Дефолтная история рендерилась пустой и схлопывался inline-flex.
  Теперь `args` содержат `icon`/`label`, `Default` передаёт slot-контент явно;
  добавлены `Matrix` (размеры x варианты) и `WithIcon`.
- **Divider**: горизонтальный вариант демонстрировался внутри одной строки
  (`span | span`), где он визуально работал разделителем колонок. Теперь история
  показывает его между группами элементов; добавлена `Mixed` с обоими направлениями.
- **IconGallery**: иконки были без фиксированных контейнеров и различались по
  оптическому весу. Каждая обёрнута в блок `w-8 h-8` с фоном карточки, сетка
  пересчитана на 8 колонок.
- **Select**: `options` объявлялись в модуле историй, но не попадали в `meta.args`,
  поэтому дефолтная история открывала пустой список. `options` перенесён в `meta.args`,
  истории читают их из `args`.

### Migration

- Пути импорта компонентов изменились: `@/components/ui/<Name>` →
  `@/components/atoms/<Name>` или `@/components/molecules/<Name>`.
