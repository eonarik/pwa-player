# Changelog 0.17.x

> Релизы: 0.17.4, 0.17.3, 0.17.2, 0.17.1, 0.17.0

## [0.17.4] — 2026-11-11

Архитектурный рефакторинг: разрыв циклов ядро ↔ плагины, DI через composition
root, типизированная шина событий, разбиение крупных модулей, брендовый ID,
тест графа импортов. Деплой переведён на Docker Compose.

### Added

- Шина событий (`eventBus`) вместо прямых связей `MetadataService → player` и
  `DownloadSpaceService → SyncService`.
- `PluginContextDeps` + composition root в `main.ts` — разрыв рантайм-цикла
  `plugins/* ↔ stores/*`.
- Брендовый ID (`types/ids.ts`) для route-параметров/JSON/IDB.
- Тест графа импортов (`architecture.spec.ts`).
- `LibrarySource.handleAuthCallback()` — ядро больше не знает о `yandex`.
- Docker Compose вместо PM2 в CI/CD.
- `logger.debug`.

### Changed

- `uiSettings` → пакет `stores/uiSettings/` (схема, состояние, миграции).
- `MetadataService/apply.ts` → каталог `apply/` (candidate/id3/manual/remote/merge).
- `DownloadOrchestrator` → фасад над `active-downloads`/`single-track`/`batch`/`manage`.
- `BackupService` → `collect`/`restore`/`schema`.
- `RadioBrowserClient` → `radio/browser/{api,client,types}`.
- Крупные Vue-компоненты (`PodcastCatalog`, `LogiiView`, `TrackActions`,
  `TrackMetadataModal`, `TrackListPage`) разбиты на подкомпоненты и composables.
- `console.*` → `logger.*` по всему коду.
- `MetadataService/reset` и `DownloadSpaceService` переведены на шину событий.
- `types/library.ts` удалён, импорты — напрямую в `types/track|album|...`.

### Removed

- `types/library.ts`, `plugins/remoteLoader.ts`, `composables/useTrackDownload.ts`,
  `useDownloadOrchestrator.ts`, PM2-деплой.

### Internal

- Новые спеки (`contextDeps`, `registry`, `tooltip`, `logger`, `ids`,
  `backup/schema`, `download/*`, `composables/*`); актуализированы ROADMAP и
  STRUCTURE; добавлен скрипт `tree-generate`.

## [0.17.3] — 2026-11-11

UI/UX-ревизия Логий: новая шапка `FolderView`, `FolderActionsMenu`, hover-кнопки,
отдельный `LogiiIntroView`, галерея с загрузкой/удалением, `InputWithAffix`,
авторесайз `Textarea`, `data-testid` для всех e2e.

### Added

- `FolderActionsMenu` в `FolderHeader`: действия плагинов, плейлист-сабменю,
  «Скачать всё» (рекурсивно).
- `PluginExtension.folderActions` — контракт для кнопок-действий плагинов в шапке
  папки; `yandexSelf` реализует «Добавить сезон».
- `InputWithAffix` (prefix/suffix), `LogiiIntroView` (только Vibe + чат),
  `LogiiVibeBlock`, загрузка/удаление картинок в `LogiiGallery`, `Textarea`
  с `autoResize`.
- `data-testid` для всех интерактивных элементов Логий и модалок
  (полный список — в `e2e/helpers/logii-helpers.ts`).

### Changed

- `FolderHeader` — только breadcrumb + счётчик + меню действий; вторая строка
  (search/sort/metadata/sync) убрана как дубль `FolderFilters`.
- `FolderFilters` принимает `subtreeTracks` (нужны все треки поддерева).
- Hover-кнопки rename/delete в колонках Логий — `IconButton`, только на hover,
  с градиентным фоном под длинными именами.
- `CreateFolderModal` — `InputWithAffix` (prefix виден в поле, preview убран).
- `CreateTopsModal` — `suffix=".txt"`, лимит 1..20, idempotent-обработка имени.
- `SearchInput` — prop `testId` прокидывается в `<input>`.
- `LogiiChat` — редактирование/удаление комментариев, `Textarea` с авторесайзом.

### Fixed

- `POST /folder` в `mockLogii` возвращает 409 при существующей папке.
- `PUT /upload` не парсил `image/*` (заменено на `type: '*/*'`).
- `renameFolderSubtree` не обновлял `folder.name` (см. 0.17.2).
- `removeResource` не убирал `sources` у треков поддерева (см. 0.17.2).
- `<input type=file>` в `LogiiTrackTab` не рендерился в пустой папке (см. 0.17.2).
- `folder-sync-trigger`: семантическая проверка через `data-syncing` вместо
  `toHaveCount(0)`.
- `LogiiPanel` не сбрасывал `activeTab` при переходе трек → intro.
- `LogiiPanelHeader` показывал табы для Intro.

### Internal

- E2E `24-logii-gallery`, обновлён `22-logii-tops` (intro.txt); `Button`/`Textarea`
  получили нужные пропсы/эмиты.

## [0.17.2] — 2026-11-10

Создание и редактирование в Логиях: сезоны, авторы, топы, комментарии,
загрузка/удаление треков. Серверный write API для `yandex-self`. Массовая замена
хрупких e2e-локаторов на `data-testid`.

### Added

- UI Логий: `CreateFolderModal`, `CreateTopsModal`, `useYandexSelfWrites`,
  редактирование/удаление комментариев в `LogiiChat`, кнопки «+ автор», «+ топы»,
  «Загрузить треки», «Удалить с Диска».
- Серверный write API `yandex-self`: `POST /folder`, `DELETE /resource`,
  `POST /move`, `PUT /upload` (≤ 30 МБ).
- Фронт: `createFolder`, `removeResource`, `moveResource`, `uploadFile`;
  `LibraryWriter.removeTrackSource`, `renameFolderSubtree`;
  `PluginExtension.folderActions`.
- E2E: комментарии, создание сезона, полный цикл автора, batch-топы + Intro,
  загрузка/удаление трека; stateful-мок `mockLogii` (`diskTree` мутируется).

### Changed

- `cleanupForceScanInternal` при пустых `sources` не удаляет трек (сироты чистит
  `cleanupOrphanTracks` на старте).
- `useYandexSelfWrites.removeResource` — `scanFolder(recursive, force)`, чтобы
  покрыть всё поддерево.
- `LogiiTrackTab.onDeleteTrack` — `removeResource` + точечный
  `removeTrackSource`, без force-скана.
- Комментарии в `LogiiChat` может редактировать/удалять любой пользователь
  (не по нику).
- E2E-локаторы `plugin-*`, `folder-sync-*` переведены на `getByTestId`.

### Fixed

- `renameFolderSubtree` не обновлял `folder.name`.
- `removeResource` не убирал `sources` у треков поддерева (`recursive: true`).
- `<input type=file>` не рендерился в пустой папке.
- `folder-sync-trigger` `toHaveCount(0)` не работал (кнопка всегда в DOM).
- `strict mode violation` в `author-*`/`folder-*` (test-id на row и кнопках).
- E2E-мок `download` отдавал `audio/mpeg` для картинок.
- E2E-мок `mockLogii` не был stateful (create/remove не отражались в `GET`).

### Internal

- Сервер `yandex-self` разбит на `middleware/`, `routes/`, `index.js`; полное
  покрытие `routes.spec.js`. `data-testid` на всех интерактивных элементах
  (полный список — в `e2e/helpers/logii-helpers.ts`).

## [0.17.1] — 2026-11-09

Доработка Логий: рекурсивное обновление, воспроизведение по автору, навигация
«К папкам», e2e-покрытие.

### Added

- Play/pause поверх аватара автора: play-all по всем трек-папкам автора
  (без Intro), повторный клик — пауза.
- Уникальный цвет аватара от хэша имени; `simpleHash` (djb2) вынесен в утилиту.
- Кнопка «К папкам» в `LogiiPanelHeader`.
- `resolveLogiiNavigationAfterRefresh` — после рекурсивного refresh возвращает
  ближайший существующий уровень.
- E2E: read-only навигация, play-all автора, «К папкам», рекурсивный refresh,
  редактирование Vibe.

### Changed

- `onRefresh` — `scanFolder({ recursive: true, force: true })` + авто-навигация
  на ближайший существующий уровень.
- Автовыбор автора/папки объединён в один `watch` с `immediate: true`; после
  refresh не уводит в первую попавшуюся папку.
- `goToAuthor`/`goToFolder` передают `params.path` массивом.
- `LogiiAuthorsColumn`: `hasTracks` больше не блокирует play-author, только
  `aria-disabled`.

### Fixed

- `LogiiView` не выполнял автовыбор при повторном заходе.
- После `router.replace` на уровень автора автовыбор уводил в первую папку.
- Play у автора не заменял существующую очередь.

### Internal

- E2E `15`–`18`, хелперы в `logii-helpers.ts`; `mockLogii` ставится после
  `mockAllApis`, `bootstrapLogii` ждёт появления корня `yandex-self`.
- Backend: сетевые ошибки `zvuk`/`yandex` логируются через `logger` без stack
  (вместо `console`).

## [0.17.0] — Логии (yandex-self)

Переработка `yandex-self` в мультифункциональный плагин «Логии». Ядро не знает
о специфике — всё через `PluginExtension.folderViews`, `fileHandlers` (в будущем)
и `manifest`.

### Added

- `PluginFolderView` + `findFolderView` + `getExtensionFolderViews` — кастомные
  view папок; `FolderRoute` выбирает компонент по `match`.
- `LogiiView`: 3 колонки (авторы / папки / трек-чат-галерея).
- `parseLogii` — парсер/stringify `vibe.logii.txt`.
- Intro (напутствие) для корня автора: первый пункт в колонке папок.
- Глобальный ник (`localStorage['logii:nickname']`), авто-растущий `textarea`,
  кнопка «Обновить» (рекурсивный refresh), лоадеры и индикация отправки.
- `PluginExtension.folderViews` в `yandex-self`.

### Changed

- `FolderListItem` скрывает префикс `logii.`, показывает иконку radio.
- Авто-выбор автора/папки — `router.replace` (не засоряет историю).
- `readLogiiFile`/`writeLogiiFile` работают с любым `.txt` в папке; дефолт —
  `vibe.logii.txt`.
- `LogiiTrackItem`: `logiiFileName`, `isIntro`.

### Fixed

- 500 при чтении отсутствующего `vibe.logii.txt` (обёрнуто в `try/catch`).
- «Назад» не работал после перехода в папку Логий.
- Лоадер перекрывал аудио-треки.
- Ник не сохранялся между чатами.
- Трек из Логий падал с 500 молча (тост «Не удалось воспроизвести»).
- Трек из Логий не воспроизводился (используются реальные `Track` из `library`).
- `applyCandidate` воскрешал отключённые плагины.

### Removed

- `LogiiSeasonView`, `LogiiTrackView`, `LogiiNicknameModal`, `logiiApi.ts`,
  поллинг `vibe.logii.txt`.

### Internal

- `LogiiView` разбит на компоненты; `parseLogii.spec.ts`; `sourceKey` с `folderId`;
  `PlaylistMatcher` схлопывает диакритику (но не `й`); `metadataProviderEnabled`
  - `metadataProviderOrder` для всех провайдеров.
