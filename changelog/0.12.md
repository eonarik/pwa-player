# Changelog 0.12.x

> Релизы: 0.12.2, 0.12.1, 0.12.0

## [0.12.2] — 2026-11-01

### Added

- «Найти в Звуке» для коллекций с недоступными треками.
- `PluginCollectionAction` — кастомные действия плагинов в `TrackListPage`.
- `extMetadata` в `FetchedMetadata`/`MetadataCandidate`.
- `LibrarySource.applyCandidate`.
- Zvuk → `streaming`-source при strict-match.
- `AudioService.releaseCurrent`; `reconcileFolderTrackIds`.
- Умный скоринг Звука (`titleContainmentScore`); единый `queryZvuk` на сервере.

### Changed

- `cleanupOrphanTracks` удаляет треки с только `streaming`-source, если не
  используются.
- `TrackMerger`: виртуальные треки без совпадений — пустой `sources`.
- `TrackListPage` рендерит `PluginCollectionAction`; `AlbumSelect` переработан;
  `AlbumView`/`ArtistView`/`AlbumsView` — ссылки по `albumId`.
- `TrackRow` для недоступных — `Artist — Title`; `disconnectPlugin` освобождает
  `AudioService`.
- `ToastService.update`; сервер: ретраи 418/429 (5/10/15 с), 429 вместо 500.
- `restoreUnavailable`: `MAX_PER_RUN = 100`, задержка 2 с, прерывание при
  `RateLimitError`.
- `TrackMetadataModal`: «Найденные варианты» в `Teleport` сверху.
- `useAutoActions`: сброс флага при ошибке `runAutoFetch`.

### Fixed

- 418/дефисы в поиске Звука; сироты после удаления плейлиста; «Альбом не
  найден»; кнопка «Найти в Звуке»; `Unsafe finally`;
  `SchemaService.initPluginStores`; `yandexSelfService.logout`
  (`isDisconnected`).

### Removed

- Мёртвый код `SchemaService.initPluginStores`; реэкспорты `store.ts`,
  `MetadataService.ts`.

### Internal

- Распил `AudioService` (hls/resources/events), `library/store`
  (state/persist/computed/actions/cleanup/reconcile), `MetadataService`
  (types/persistence/resolve/apply/reset/fetch); спеки `albums`, `cleanup`,
  `reconcile`, E2E `08`–`10`.

## [0.12.1] — 2026-11-01

### Added

- `Folder.trackIds` (папка хранит свои треки).
- `logger`; `AutoFetchRegistry`; `playbackVersion`.

### Changed

- `MetadataService`: строгое совпадение обновляет все поля, нестрогое —
  только альбом/обложку; `fetchAndApply` как единая точка входа; `reset`
  корректно отвязывает от альбома и не кэширует `not-found`.
- `MetadataCandidatesModal` переработан (обложки, артист, альбом, провайдер).
- `TrackMetadataModal`: `AlbumSelect` вместо `CoverPicker`.
- `TrackActions`: сброс `processedTracks` при удалении метаданных.
- E2E полностью на `data-testid`/`expect.poll`, без `waitForTimeout`.

### Fixed

- Автопоиск после сброса; `30 Seconds to Mars` не перезаписывается; мульти-
  источники в папках; ошибки Звука не блокируют фоллбэк на iTunes.

### Removed

- Неиспользуемые свойства `TrackListPage`; отладочный `05-metadata-direct`.

## [0.12.0] — 2026-11-28

### Added

- `FolderStatusService` — реактивные статусы папок с персистом.
- Прогрессивный рендеринг (`onChunk`).
- Отмена фонового сканирования; персистентность библиотеки в IDB;
  `deepToRaw`; E2E архитектуры; in-memory FS для тестов.

### Changed

- Плеер пропускает треки при падении всех источников.
- `scanAll` не добавляет стартовую папку; иерархия статусов `scanning`.
- E2E — `expect.poll`/`waitForResponse` без `waitForTimeout`.

### Fixed

- 404 при пробелах (`encodeURIComponent`); дубли путей Яндекс.Диска;
  `DataCloneError`; пропажа треков при фоновом скане / после F5;
  `strict mode violation`; `indexedDB is not defined` в тестах подкастов.

### Removed

- `FolderUiState`, `getFolderStateStore`, `stores/folderUi.ts`.
